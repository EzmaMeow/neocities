Read Me

[About this page] This page is mostly for notes and info related to this site. It is not meant to be expose to the main site and is expected to sit in the directory for reference.

### File structure The file structure at the time of writing this is a bit of a mess. The ideal structure is to have a global and (optional) local directory for each resource type and to wrap the pages into their own directory or group together with similar types. - Globals: - Data : Text files or binary data. May contain html. - Assets : General location of art and media files. - Styles : CSS files that mulitple pages uses. - Lib : JS modules that are more independent and design to be resused. - Scripts : Site wide JS. - Other Dir: - Pages : Files for standalone webpages. They should be in their own directory containing at least an index.html. - Posts : Html or markdown format txt files that represent a post. (the posts page will render them if correctly added to the sitemap) - Games : Files related to games. They should be in their own directory, but are not expected to have an index.html - Widgets : Files that are meant to build or handle elements in webpages. - Other files: theses are related to the landing page or the site in general. - index.html - styles.css - script.js - sitemap.json - sitemap.html - not_found.html - readme
