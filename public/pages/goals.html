Main Goal

I would like to either make or be part of a project that provides code that solve problem independent segments as well as being open source and close to public domain. The idea is the systems are meant to be used to build more complex systems either to learn from, use as is, or use and improve. They are also should focus on being simple and any possible dependencies be abstracted.

I am focusing more on code focusing on systems to be used to build games for the web, though I may make random stuff for use on this website or others. These are base framework and not a dedicated engine. I may have a implemented system to test or demostrate it which follow a diffrent set of rules. Generally the system I make should be able to be swap out with existing systems with some work. Also my system will be subjected to change for some time untill I get a soild game or more running with them and spend time cleaning them up.

The reasons is because I am tired of working around limitations or dealing with bloat when making web games. Also to try to evade copywrite issues dealing with redistribution since it seems I have to depend on an unoffical online export if I do not want to clone the code to my directoty. I also do not like hosting code that require additional downloads beside the language (aka python, web browser with js support, or similar cases) to run or work on it.
There is also the case that I think it be better to learn or make games from the ground up for those who are more focus on the code than the art. This is because a lot of little things can be misses working with only an existing engine. Then when working on a system that chanegs physics or rendering, the game start to get slower due to various reasons between either not handling it correctly or the engine limitation.
