This is a experimental page that parses the input text through a few text parsers that may be used in this site.

Currently there is a custom markdown parser with some specail bbcode style additions such as [color=blue]text[/color] and a few other.

There is a varible replacer that will replace expressions like %random to something if it exists (random will be replace by a random float between 0-1)

There is also an inline function parser, but it mostly to exposed $calc() which will solve simple math expressions that is passed as a parameter

NOTE: the html is wrap in a span tag with a markdown-render class. This is to allow markdown styling to be appled to the elements inside it and it is not really needed.
